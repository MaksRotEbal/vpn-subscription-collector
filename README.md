# VPN Subscription Collector

Автоматический сборщик и сортировщик **публичных** VPN-подписок для личного использования. Агрегирует URI из настроенных открытых источников, удаляет дубликаты, классифицирует узлы по типу обхода (БС / ЧС), определяет страну и формирует подписки (~100 серверов в файле) в формате base64 для Clash / v2rayN / Hiddify и аналогов.

> **Дисклеймер.** Проект предназначен только для образовательных целей и личного использования. Используйте только **легально доступные** публичные источники, которые вы сами добавили в `config/sources.yaml`. Авторы не гарантируют работоспособность, безопасность и законность узлов. Соблюдайте законодательство вашей страны; ответственность за использование лежит на вас. Репозиторий не содержит платных или приватных ключей.

## Протоколы и обход блокировок (2025–2026)

Краткий обзор по открытым материалам и практике сообщества (не юридическая консультация):

| Протокол | Назначение | Заметки для РФ |
|----------|------------|----------------|
| **VLESS** (+ REALITY / TLS) | Основной стек Xray; низкий оверхед, маскировка под HTTPS | Часто рекомендуется для обхода DPI; сочетание с REALITY снижает fingerprint |
| **VMess** | Предшественник VLESS в экосистеме V2Ray | Поддерживается; чаще уступает VLESS+REALITY по «невидимости» |
| **Trojan** | TLS-подобный трафик | Работает через стандартные порты 443 |
| **Shadowsocks (ss)** | Лёгкое шифрование | Зависит от метода и обфускации; проще детектировать без доп. слоёв |
| **Hysteria2 (hy2)** | QUIC/UDP, высокая скорость | Полезен при ограничениях TCP; UDP может фильтроваться провайдером |
| **TUIC** | QUIC-based | Аналогично — зависит от сети |
| **WireGuard** | Нативный VPN | Часто блокируется по сигнатуре; реже используется для «тонкого» обхода |

**БС (белый список)** — режимы, когда доступны только одобренные SNI/операторские ресурсы (мобильный интернет, whitelist TLS). В именах ищутся теги: `whitelist`, `mobile`, `mts`, `белый`, `бс` и т.д. (см. `config/classification.yaml`).

**ЧС (чёрный список)** — обычный режим обхода блокировок вне whitelist. Теги: `blacklist`, `чс`, `cs`, `чёрный` и др. По умолчанию нераспознанные узлы помечаются как **ЧС**.

С 2025 года в РФ усилились методы «заморозки» TLS-потоков и whitelist по SNI/CIDR ([обсуждение net4people](https://github.com/net4people/bbs/issues/490)). Эффективность конкретного узла зависит от провайдера, времени суток и конфигурации — коллектор **не проверяет** доступность серверов.

## Как это работает

1. Читает URL из `config/sources.yaml` (только с `enabled: true`).
2. Загружает тело подписки (plain URI или base64).
3. Парсит `vless://`, `vmess://`, `trojan://`, `ss://`, `hysteria2://`, `hy2://`, `tuic://`, `wireguard://` и др.
4. Дедуплицирует по `протокол + хост + порт`.
5. Классифицирует **БС/ЧС** по ключевым словам в исходном имени.
6. Определяет страну: эмодзи-флаг, код `DE`/`NL` в имени, TLD хоста (`.de`, `.nl`).
7. Переименовывает узел в вид: `🇳🇱 Netherlands БС` или `DE ЧС`.
8. Пишет в `output/`:
   - `all-bs.txt`, `all-cs.txt` — base64-подписки (декодируйте base64 для просмотра URI);
   - `by-country/<cc>-<bs|cs>[-NNN].txt` — разбивка по стране и типу;
   - `meta.json` — статистика.

## Быстрый старт

```bash
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt
python scripts/collect.py       # загрузка из включённых источников
python scripts/collect.py --offline   # без сети, тестовые URI
pytest tests/ -q
```

## Настройка источников

Отредактируйте `config/sources.yaml`:

```yaml
sources:
  - name: my-list
    url: "https://raw.githubusercontent.com/.../list.txt"
    enabled: true
```

Примеры **публичных** GitHub-агрегаторов (проверяйте лицензию и актуальность сами):

- [ebrasha/free-v2ray-public-list](https://github.com/ebrasha/free-v2ray-public-list) — VLESS, VMess, Trojan, SS, Hysteria2
- [roosterkid/openproxylist](https://github.com/roosterkid/openproxylist) — `V2RAY_RAW.txt`
- [hans-thomas/v2ray-subscription](https://github.com/hans-thomas/v2ray-subscription)

По умолчанию включён один облегчённый источник ebrasha; остальные отключены.

Правила БС/ЧС и страны — в `config/classification.yaml`.

## GitHub Actions

Workflow `.github/workflows/update-subscriptions.yml`:

- ежедневно в 06:00 UTC;
- при push в `main`/`master`, если менялись `config/` или `scripts/`;
- вручную через `workflow_dispatch`.

Требуется разрешение `contents: write` для коммита `output/*` в репозиторий.

**Fork:** включите Actions в настройках форка, при необходимости измените `cron` и список источников.

## Структура проекта

```
config/
  sources.yaml           # URL источников
  classification.yaml    # БС/ЧС, страны, TLD
scripts/
  collect.py             # основной скрипт
tests/
  test_collect.py
.github/workflows/
  update-subscriptions.yml
output/                  # генерируемые подписки (коммитятся CI)

README.md
```

## Ограничения

- Нет проверки живости серверов (ping/handshake).
- GeoIP по IP не используется — только эвристики имени и TLD.
- Качество публичных списков непредсказуемо; возможны нерабочие или небезопасные узлы.
- Часть URI может не распарситься из-за нестандартного формата.

## Лицензия и этика

Используйте только открытые источники, которые явно распространяются для публичного доступа. Не добавляйте украденные или платные подписки.
